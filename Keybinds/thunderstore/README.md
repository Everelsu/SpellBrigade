# Keybinds Unlocked

*Rebind every key and controller button — right in the game's Options menu.*

Version 1.0.1 · The Spell Brigade 1.1.4 · MelonLoader 0.7

## Features

- **Keyboard & mouse and controller** — two columns, rebind each separately. Mouse buttons work too.
- **Everything that matters** — movement, pause, stats, tooltips, emote wheel, ping, quick chat, and menu actions like tabs, ready, invite, prestige, refund, lobby code and more.
- **On-screen key icons follow your keys** — the Q/E tab hints, the Ready button and other prompts show your new keys. If the game has no icon for a key, the mod draws one in the same style.
- **Conflict warnings** — if your new key is already used by another action in the same section, both are highlighted in orange.
- **Works everywhere** — main menu and pause menu, with mouse, keyboard or gamepad (the list scrolls to follow your selection).

## Installation

1. Install [MelonLoader](https://github.com/LavaGang/MelonLoader/releases) (0.7.x) for The Spell Brigade and launch the game once.
2. Put **KeybindsUnlocked.dll** into `<Game folder>\Mods\`
3. Launch the game → **Options → Controls**.

## How to use

- Click (or select and confirm) the key you want to change, then press the new key or button.
- **Esc** cancels. If you press nothing for 10 seconds, the change is cancelled too.
- **Reset all** at the bottom of the list returns every key to default.

## FAQ

**Where are my keybinds saved?**  
In `<Game folder>\UserData\KeybindsUnlocked.json`. Delete the file to reset everything.

**Does it work in co-op?**  
Yes. Keybinds are yours alone and don't affect other players.

**How do I uninstall?**  
Delete **KeybindsUnlocked.dll** from the Mods folder — the game goes back to its default keys.

**Is it compatible with other mods?**  
Yes, including Gold & XP Multiplier — both add their own things to the Options menu.
