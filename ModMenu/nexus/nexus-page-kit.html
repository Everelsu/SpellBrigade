Mod Menu 1.0.0

Всё, чтобы создать страницу мода: поля для заполнения, описание в BBCode с предпросмотром и порядок действий. Кнопка «Копировать» кладёт текст в буфер обмена, дальше вставляете в редактор Nexus.

Поля страницы

Название
Mod Menu
Краткое описание (Summary)
Options → Mods: every mod's settings in one list, built from the game's own UI. Foldable sections, search, reset to default, mouse wheel on selectors. Open API for mod authors. Requires MelonLoader.
Версия
1.0.0
Категория
Utilities
Если такой категории у игры нет, подойдёт Miscellaneous.
Требования (off-site)
https://github.com/LavaGang/MelonLoader/releases
Название требования: MelonLoader 0.7.x
Описание файла
Main file. Put Mods/ModMenu.dll into your game folder and launch the game.

Порядок действий

      
    
        
  1. Upload → Add mod: игра The Spell Brigade, название, Summary, версия и категория — значения слева.
    2. 
        
  2. Description: переключите редактор в режим BBCode (значок [ ]) и вставьте описание.
    3. 
        
  3. Files: загрузите ModMenu-1.0.0.zip как Main file, версия 1.0.0.
    4. 
        
  4. Requirements: добавьте MelonLoader как off-site требование.
    5. 
        
  5. Images: thumbnail.png (1280×720) — основное изображение (Primary), header.png (1400×400) — шапка страницы (Header).
    6. 
        
  6. По желанию: добавьте ссылки между страницами своих модов для The Spell Brigade (Gold & XP Multiplier, Keybinds Unlocked, Skip Intro, Run Customizer, More Players, Mod Menu, Pinned Challenges).
