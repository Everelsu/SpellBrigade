Cyrillic Fonts 1.1.0

Всё, чтобы создать страницу мода: поля для заполнения, описание в BBCode с предпросмотром и порядок действий. Кнопка «Копировать» кладёт текст в буфер обмена, дальше вставляете в редактор Nexus.

Поля страницы

Название
Cyrillic Fonts
Краткое описание (Summary)
Родные шрифты игры с кириллицей: заголовки и кнопки — Irish Grover, остальной текст — Titillium Web, как в английской версии, вместо простого запасного шрифта. Латиница не меняется. Нужен MelonLoader.
Версия
1.1.0
Категория
User Interface
Если есть категория Translations, подойдёт и она.
Требования (off-site)
https://github.com/LavaGang/MelonLoader/releases
Название требования: MelonLoader 0.7.x
Описание файла
Основной файл. Положите Mods/CyrillicFonts.dll в папку игры — шрифты уже внутри. Лицензии шрифтов — в Mods/CyrillicFonts-FONTS-LICENSE.txt.
Changelog 1.1.0
Три вида кириллицы в заголовках: Гибрид (новый, по умолчанию) — общие с латиницей буквы от Irish Grover, остальные нарисованы от руки; Классика — как в 1.0.0; Рисованный — весь алфавит от руки Вид шрифта и размер кириллицы меняются прямо в игре через Mod Menu (Настройки → Mods → Cyrillic Fonts), без перезапуска Новая настройка HeadingStyle в MelonPreferences.cfg (Hybrid / Classic / Drawn)


      
Порядок действий

      
    
        
  1. Upload → Add mod: игра The Spell Brigade, название, Summary, версия и категория — значения слева.
    2. 
        
  2. Description: переключите редактор в режим BBCode (значок [ ]) и вставьте описание.
    3. 
        
  3. Files: загрузите CyrillicFonts-1.1.0.zip как Main file, версия 1.1.0.
    4. 
        
  4. Requirements: добавьте MelonLoader как off-site требование.
    5. 
        
  5. Images: thumbnail.png (1280×720) — основное изображение (Primary), header.png (1400×400) — шапка страницы (Header). Скриншоты «до/после» на русском (настройки, лобби, итоги забега) будут очень кстати.
    6. 
        
  6. По желанию: в Permissions отметьте, что в моде есть чужие шрифты (Irish Grover — Apache 2.0, Titillium Web — SIL OFL), их авторы указаны в описании.
    7.
