# More Players

Break the 4-player limit in The Spell Brigade.

## Features

- Up to **8 players** by default, configurable from 4 to 16 (`MaxPlayers` in `UserData\MelonPreferences.cfg`)
- Lobby split into rooms of 4 seats, the full player list on **Tab**
- Capture-point speed and zone radius keep scaling past 4 players

## Co-op

⚠️ **Every player in the lobby needs the mod.**

## Install

**Manual:** install [MelonLoader](https://github.com/LavaGang/MelonLoader/releases) **0.7.x** for The Spell Brigade, launch the game once, then drop `Mods/MorePlayers.dll` into the game's `Mods` folder:

```
<Steam>\steamapps\common\The Spell Brigade\Mods\
```

The mod prints a one-line status to `MelonLoader\Latest.log` when it loads. To uninstall, delete the DLL.

Built for The Spell Brigade 1.1.4. If a game update changes a hooked method, that hook is skipped with a clear log line and the rest keeps working.
