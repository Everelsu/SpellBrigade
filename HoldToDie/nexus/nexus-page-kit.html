Hold to Die 1.0.0

Всё, чтобы создать страницу мода: поля для заполнения, описание в BBCode с предпросмотром и порядок действий. Кнопка «Копировать» кладёт текст в буфер обмена, дальше вставляете в редактор Nexus.

Поля страницы

Название
Hold to Die
Краткое описание (Summary)
Bad run? Hold a key in a run to die on the spot: a ring fills around your wizard, then the game handles the death as usual. Optional no-revives mode ends the run right away. Requires MelonLoader.

Порядок действий

      
    
        
  1. Upload → Add mod: игра The Spell Brigade, название, Summary, версия и категория — значения слева.
    2. 
        
  2. Description: переключите редактор в режим BBCode (значок [ ]) и вставьте описание.
    3. 
        
  3. Files: загрузите HoldToDie-1.0.0.zip как Main file, версия 1.0.0.
    4. 
        
  4. Requirements: добавьте MelonLoader как off-site требование.
    5. 
        
  5. Images: thumbnail.png (1280×720) — основное изображение (Primary), header.png (1400×400) — шапка страницы (Header). Скриншот кольца вокруг волшебника в забеге тоже будет кстати.
    6. 
        
  6. По желанию: добавьте Mod Menu как необязательное требование (Nexus-мод) — в нём настройки клавиши и режима, и ссылку отсюда туда.
    7.
