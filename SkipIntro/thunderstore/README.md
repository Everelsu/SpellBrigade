# Skip Intro

Version 1.0.0 · The Spell Brigade 1.1.4 · MelonLoader 0.7

## What it skips

- Studio logos screen
- BoltBlaster Games and VAF intro videos

The mod uses the game's own skip.

The first-launch consent screen is left as is: it only appears once and stores your choice.

## Installation

1. Install [MelonLoader](https://github.com/LavaGang/MelonLoader/releases) (0.7.x) for The Spell Brigade and launch the game once.
2. Put **SkipIntro.dll** into `<Game folder>\Mods\`
3. Launch the game.

No settings, nothing to configure.

## FAQ

**How do I get the intro back?**  
Delete **SkipIntro.dll** from the Mods folder.

**Does it work in co-op?**  
Yes. It only affects your own game start; other players don't need it.

**Is it compatible with other mods?**  
Yes, including Gold & XP Multiplier and Keybinds Unlocked.
